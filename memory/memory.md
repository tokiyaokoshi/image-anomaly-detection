# 異常検知モデル構築プロジェクト: 進捗と今後の研究方針

## 1. プロジェクトの目的と概要
*   **タスク:** VAE (Variational Autoencoder) を用いた画像ベースの教師なし異常検知 (Unsupervised Anomaly Detection)。
*   **対象データ:** 工業製品（ボトル）の真上からの画像。
*   **アプローチ:** 再構成ベース (Reconstruction-based)。正常データのみで学習したモデルにテスト画像を入力し、入力と出力（再構成画像）の差分から異常を検出する。

## 2. これまでの実装と検証内容
### 2.1 構築したモデルアーキテクチャ
画像の局所的な特徴と大域的な特徴を捉えるため、以下の4パターンのモデルを実装・比較検証できる環境を構築した。入力画像サイズは `128x128`。
1.  **VAE_FC**: 全結合層のみのベースライン。
2.  **VAE_CNN_Shallow3**: 浅い3層のCNN。
3.  **VAE_CNN_Deep5**: 深い5層のCNN。
4.  **VAE_Hybrid_CNN_FC**: 深いCNNによる空間的特徴抽出と、FCによる全体的特徴の圧縮を組み合わせたハイブリッドモデル。

### 2.2 異常スコアの算出と閾値の自動設定
*   **異常スコア計算:** 入力画像と再構成画像の Structural Similarity (SSIM) を計算し、`1.0 - ssim_map` で異常度マップを生成。その中の上位Kパッチ (Top-130) の平均誤差を最終的な異常スコアとする。
*   **客観的な評価パイプラインの構築:** 人間の目視による恣意的な閾値設定を排除し、モデル間の純粋な性能比較を行うため、以下の2つの手法を実装。
    *   **AUROCによる地力評価:** 閾値に依存しないモデルの純粋な異常分離能力を測定。
    *   **F1スコア最大化:** PR曲線からF1スコアが最大となる最適閾値を探索し、定量指標（Accuracy, Precision, Recall, F1）と混同行列を自動出力。

### 2.3 データ拡張 (Data Augmentation) の実施
*   ボトル画像の特性（真円に近い）を活かし、背景の白枠を維持したまま「36度ずつの均等回転（10パターン）」を行うオフラインデータ拡張を実施。
*   学習用データを209枚から2090枚へ拡張。※検証（テスト）データは実環境を想定し拡張せず元の43枚を使用。

## 3. 現在の課題と最新論文からの知見
データ拡張後、最も表現力の高いハイブリッドモデルで再学習を行った結果、AUROCが低下（0.9683 → 0.9460）し、一部の異常画像を見逃す現象が発生した。

この現象は、最新論文 *“Mitigating the reconstruction-detection trade-off in VAE-based unsupervised anomaly detection” (2026)* における指摘と完全に一致している。

*   **再構成と検出のトレードオフ:** VAEの表現力が高すぎる（正常画像を綺麗に復元できる）と、未知の異常（キズなど）まで「正常な形」として忠実に再構成（ヒーリング）してしまい、結果的に入力との差分が消え、異常検知精度が低下する。
*   **対応済みの手法:** 同論文で特効薬とされる「$\beta$-スケジューリング（アニーリング）」は、現在のモデルの損失関数（KLDウェイトの漸次増加）として実装・適用済みである。

## 4. 今後の研究方針 (Next Steps)
モデルが賢くなりすぎて異常まで復元してしまう「トレードオフ」を根本的に打破するため、以下のステップで研究を進める。

1.  **Sparse VAE の理論解読と実装:**
    *   論文で最も有効とされた、潜在空間（Latent Space）に適応的なドロップアウト（Gaussian Dropout等）を課す **Sparse VAE** の機構を導入する。
    *   AIの表現力（記憶容量）をあえて「スカスカ（疎）」に制限することで、「正常な基本構造しか記憶・復元できず、イレギュラーなキズは復元できないモデル」を構築する。
    *   論文著者の公式GitHubのコードを参考に、損失関数や潜在変数のサンプリングロジックを既存のモデル（Hybrid_CNN5_FC等）に組み込む。
2.  **再現検証と定量的比較:**
    *   Sparse VAE化されたモデルで学習を行い、AUROC等の指標を用いて、データ拡張後の見逃し問題が解消され、トレードオフが緩和されるかを確認する。
3.  **新規性の追求 (独自手法のアドオン):**
    *   論文の再現にとどまらず、これまでの知見を活かした独自のアプローチ（例: 画像ピクセル領域のSSIM誤差と、潜在空間のKLDスコアのハイブリッド統合など）を追加実装し、さらなる異常検知精度の向上を目指す。
