## 2. 研究の目的と現在地

- 主目的は、正常画像のみで学習したVAEによる**bottle画像の異常検知性能向上**。
- transistorで通常・固定回転・ランダム回転を比較し、その後bottleで通常・ランダム回転を比較済み。最近の結果と考察は[実験結果と考察](実験結果と考察.md)の第2〜5節に集約した。
- 今回の条件では、元の向きで通常学習が良好だった一方、広い向きの合成回転画像ではランダム回転学習が良好だった。復元の細部のぼけ・明暗の省略には課題が残る。
- 当面はHybrid CNN＋FCを継続し、モデル選定は先送り。損失はSSEを採用し、βは別途調整する。異常検知性能はAUROCで評価する。具体的な定義と履歴は[研究方針](研究方針.md)を参照。
- Sparse VAEは原論文から理論の理由を理解する段階で、本研究への実装・改善効果は未検証。
- 次の候補は、回転への対応と細部の復元の両立、およびbottleの細部の省略が異常スコアに与える影響の確認。具体的な実験条件は未決定。
