# 異常検知モデル構築プロジェクト: 進捗と今後の研究方針

## 1. プロジェクトの目的と概要
*   **タスク:** VAE (Variational Autoencoder) を用いた画像ベースの教師なし異常検知 (Unsupervised Anomaly Detection)。
*   **対象データ:** 工業製品（ボトル）の真上からの画像。
*   **アプローチ:** 再構成ベース (Reconstruction-based)。正常データのみで学習したモデルにテスト画像を入力し、入力と出力（再構成画像）の差分から異常を検出する。

## 2. これまでの実装と検証内容
### 2.1 構築したモデルアーキテクチャ
画像の局所的な特徴と大域的な特徴を捉えるため、以下の4パターンのモデルを実装・比較検証できる環境を構築した。入力画像サイズは `128x128`。
1.  **VAE_FC**: 全結合層のみのベースライン。
2.  **VAE_CNN_Shallow3**: 浅い3層のCNN。
3.  **VAE_CNN_Deep5**: 深い5層のCNN。
4.  **VAE_Hybrid_CNN_FC**: 深いCNNによる空間的特徴抽出と、FCによる全体的特徴の圧縮を組み合わせたハイブリッドモデル。

### 2.2 異常スコアの算出と閾値の自動設定
*   **異常スコア計算:** 入力画像と再構成画像の Structural Similarity (SSIM) を計算し、`1.0 - ssim_map` で異常度マップを生成。その中の上位Kパッチ (Top-130) の平均誤差を最終的な異常スコアとする。
*   **客観的な評価パイプラインの構築:** 人間の目視による恣意的な閾値設定を排除し、モデル間の純粋な性能比較を行うため、以下の2つの手法を実装。
    *   **AUROCによる地力評価:** 閾値に依存しないモデルの純粋な異常分離能力を測定。
    *   **F1スコア最大化:** PR曲線からF1スコアが最大となる最適閾値を探索し、定量指標（Accuracy, Precision, Recall, F1）と混同行列を自動出力。

### 2.3 データ拡張 (Data Augmentation) の実施
*   ボトル画像の特性（真円に近い）を活かし、背景の白枠を維持したまま「36度ずつの均等回転（10パターン）」を行うオフラインデータ拡張を実施。
*   学習用データを209枚から2090枚へ拡張。※検証（テスト）データは実環境を想定し拡張せず元の43枚を使用。

## 3. 現在の課題と最新論文からの知見
データ拡張後、最も表現力の高いハイブリッドモデルで再学習を行った結果、AUROCが低下（0.9683 → 0.9460）し、一部の異常画像を見逃す現象が発生した。

参照論文 *“Mitigating the Reconstruction-Detection Trade-off in VAE-based Unsupervised Anomaly Detection” (2026)* は、正常画像の再構成品質と異常検出性能のトレードオフを報告している。本研究の性能低下にも関係する可能性はあるが、原因が同一であると確認したわけではない。

*   **再構成と検出のトレードオフ:** 制約を弱めたVAEは未知の異常まで保持して復元し、入力との差が小さくなることがある。逆に正常な構造まで崩すと誤検出につながる。異常を消して正常に近い画像へ戻す「擬似正常化」は、本来目指す動作であり、異常を忠実に復元することとは区別する。
*   **既存のアニーリングと論文の違い:** 現コードは50エポックでβを0から1へ単調に増やす方式。論文は3周期でβを0から最大30または50へ繰り返し増やす方式であり、その再現は未実施。数値だけでなく、損失の係数・集約方法・推論方法も揃えて比較する必要がある。

## 4. 今後の研究方針 (Next Steps)
再構成品質と異常検出性能のトレードオフを緩和できるか検証するため、以下のステップで研究を進める。

1.  **Sparse VAE の理論解読と実装:**
    *   論文で最も有効とされた、潜在空間（Latent Space）に適応的なドロップアウト（Gaussian Dropout等）を課す **Sparse VAE** の機構を導入する。
    *   潜在次元ごとの学習可能なノイズにより、不要な成分への依存を弱め、正常の共通構造を保った擬似正常化を目指す。未知のキズを復元しないことや、ボトルのAUROC改善が保証されるわけではない。
    *   論文著者の公式GitHubのコードを参考に、損失関数や潜在変数のサンプリングロジックを既存のモデル（Hybrid_CNN5_FC等）に組み込む。
2.  **再現検証と定量的比較:**
    *   Sparse VAE化されたモデルで学習を行い、AUROC等の指標を用いて、データ拡張後の見逃し問題が解消され、トレードオフが緩和されるかを確認する。
3.  **新規性の追求 (独自手法のアドオン):**
    *   論文の再現にとどまらず、これまでの知見を活かした独自のアプローチ（例: 画像ピクセル領域のSSIM誤差と、潜在空間のKLDスコアのハイブリッド統合など）を追加実装し、さらなる異常検知精度の向上を目指す。

## 8. 2026-10-15：Sparse VAE論文の精読と日本語解説
*   **原本確認：** ユーザー指定の `C:\Users\tokiy\OneDrive\01_研究\参考文献\sparce VAEに関する論文\sparce VAEに関する論文.pdf`（全6ページ）を通読。著者はAgathe Senellart、Maëlys Solal、Stéphanie Allassonnière、Ninon Burgos。論文は https://arxiv.org/abs/2605.02918 。原本SHA-256は `0a4bb376961e5dedd864729e38065df929c3ed1823ac41b5da98adcd19092d4c`。
*   **研究対象と評価の違い：** 対象は3D脳FDG PET。正常画像で学習し、模擬病変のボクセル単位AP・最良Dice・擬似正常化を主に評価する。異常マップは正常検証データで標準化した残差の絶対値。SSIMは正常復元の評価に使い、本研究のSSIM Top-130スコアとは異なる。
*   **Sparse VAEの核心（P4 §5.2 式3）：** `q(z|x)=N(μ(x), diag(α⊙μ(x)^2))`。αは次元ごとの学習パラメータで、確認したコードでは画像間で共有する。分散は入力依存のμ²と結び付く。Gaussian Dropoutにより不要な次元への依存を弱める。固定確率のDropoutの追加、単なる次元数削減、全次元の厳密なゼロ化とは異なる。
*   **初期値・損失の実装確認：** 論文の初期log αは−3（α≈0.0498、対応するp=α/(1+α)≈4.74%）。公式Sparse設定のβは1。著者指定MultiVaeの `sparse_kl_divergence` を使い、通常の標準正規KLをそのまま流用しない。log αの初期化には微小な乱数があり、μ=0付近の数値安定化と正則化計算でのlog α制限もある。これらは公式コードの読み取り確認であり、実行検証ではない。
*   **推論方法（P2 §2.1）：** 論文は `x̂=D(μ(x))` と定義し、評価では平均を使う。現ボトル評価コードのサンプリング推論とは異なる。Sparseだけでなく通常VAEも同じ推論方法で比較する必要がある。
*   **重要な解釈（P3 §4、P4 §5.3）：** 擬似正常化の良いモデルは、正常と異常の潜在分布のずれが小さい傾向。潜在空間で異常を遠くへ分離することを狙う手法ではない。既存の「潜在KLDスコアとSSIMの統合」案は、この論文の直接の提案ではなく、別仮説として評価する。
*   **結果と限界（P4 表1・§5.3）：** 基準β=10に対し、SparseはAD-30のAPが51±5→56±1、rMSEが1.42±0.09→1.31±0.04。正常hhMSEは1.18±0.02→1.20±0.01（表記値×10^-3）で、正常復元を大幅改善したわけではない。30シードのAP標準偏差は3.3→2.0。実患者の画像単位AUCは全モデル約0.806〜0.810で有意な優劣なし。ボトルの画像AUROC向上や見逃し解消は未検証。
*   **再現時の注意：** 最良Diceは閾値を動かした中での最大値で、固定閾値の実運用値ではない。rMSEはahMSE/hhMSEなので両方の絶対値も確認する。表1には会議録の標準偏差の集計単位を訂正した注記がある。通常KLの定数項省略やposterior collapseの表現にも注意し、標準的な定義と区別して解説した。
