# 現在の研究方針

最終更新：2026-11-20。運用上の承認・実行・保存ルールは[運用ルール](運用ルール.md)を参照。

## 1. 目的と現在地

- 主目的は、VAEを用いた**bottle画像の教師なし異常検知性能の向上**。正常画像だけで学習し、入力と再構成の違いから異常を検出する。
- transistorは、向きの変化が明確な対象で回転拡張の性質を調べるために使用。transistorの結果だけでbottleへの効果を結論しない。
- 通常・固定回転・ランダム回転をtransistorで比較し、bottleでも通常／ランダム回転を比較済み。現状はその結果と細部の復元に関する課題を整理している。
- Sparse VAEは論文・理論の理解を進めている段階。本研究への実装・性能改善の実証はまだ行っていない。

## 2. モデル・損失・学習条件

| 項目 | 現在有効な方針 |
| --- | --- |
| 基本モデル | 当面bottle・transistorともHybrid CNN＋FC。モデル選定は先送り |
| 復元損失 | SSEを採用。MSEを採用した過去実験は履歴として残す |
| 通常VAEの損失 | SSE＋β×標準正規事前へのKL。実装時は画素・潜在次元・バッチの集計方法を明記 |
| β | 値・期間は実験設計時に決め、別途調整する |
| 新規学習のアニーリング | 更新ごとに少しずつ増加させる線形方式。比較条件間で到達値と到達までの更新数を共通化 |
| 最近の比較での具体例 | 潜在64、バッチ32、Adam、学習率0.001、6,700更新、βは初回0・3,350更新目1・以降1。今後全実験へ無条件に固定する規則ではない |

方針の履歴：2026-11-06のDeep5基本採用は11-19にHybrid継続へ変更。11-06のMSE採用は11-15にSSEへ変更。過去の階段状βや各実験の集計を、現在の方針で書き換えない。

## 3. 評価と回転処理

- 異常検知性能の比較指標は**AUROCのみ**。過去のF1・Recall等は履歴であり、現在の主評価ではない。
- 現在の評価は平均μから復元。SSIM窓11・data_range=1で `1−SSIM` マップを作り、平坦化した上位130**点**の平均を画像の異常スコアとする。独立した130パッチではない。
- 復元MSE・画像単位SSIMは復元品質の補助指標。復元品質の高さと異常検知AUROCの高さを同一視しない。
- 学習・評価の元画像、初期重み、更新数、β、前処理、推論方式を比較目的に合わせてそろえ、残る違いを記載する。
- 最近のbottle比較：中央820×820→高解像度で回転する場合は**白埋め**・最近傍・枠維持→LANCZOS128×128→白黒・0〜1。反射補完の中断実行とは区別。
- 最近のtransistor比較：元画像全体1024×1024を使用し、回転時は反射補完。回転後に同じ縮小・白黒化を行う。補完方法は再現用設定に残すが、本文のモデル名称には入れない。
- ランダム回転学習は各提示時に連続角度[0,360)から抽選する。全方向を対象とするが、有限回の抽選で全角度を網羅したとは言わない。
- 学習時の角度とテスト時の角度候補は別物。テストの整数角度・0度除外・試行数は実験ごとに記録する。

## 4. 現時点での解釈と次の検討候補

- 回転した検査画像への対応改善と、回転なしの元テストでの性能向上を分ける。bottleでランダム回転拡張を一律に標準採用する決定はまだない。
- 固定回転モデルが近い学習角度へ寄せて復元するように見える傾向は、写真比較による観察として扱う。報告では角度推定の数値・割合・推定グラフを使用しない。
- 回転への対応と細部の復元を両立するモデル・学習条件、bottleの反射や縁の明暗の省略が異常スコアへ与える影響は今後の検討候補。次のモデル・実験条件は未決定。
- Sparse VAEでは「何をするか」だけでなく「なぜその分布・正則化なのか」を原論文から説明できる理解を目指す。
- Sparse VAEを単にKL削除と説明しない。事前分布とKL由来の近似正則化の設計変更として扱い、分散αμ²・αの学習・再構成との兼ね合いを区別する。異常除去やAUROC改善、有限のαは保証しない。
