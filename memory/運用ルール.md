# 研究サポートの運用ルール

最終更新：2026-11-21。このファイルを、現在有効な運用ルールの唯一の管理先とする。

## 1. ファイル変更の承認

- `memory/memory.md`、`memory/運用ルール.md`、`memory/研究方針.md`、`memory/実験結果と考察.md`への研究記録・方針の反映は、事前承認なしで行う。今回の分割に合わせ、従来のmemory.mdへの例外をこの4ファイルへ引き継ぐ。
- ただし、記録の更新権限は、アシスタントが研究方針を独断で決定する権限ではない。ユーザーの決定、アシスタントの提案、未決定事項を区別する。
- **上記以外のファイル**（コード、ノートブック、スライド、READMEなど）の作成・変更・移動・削除は、対象と変更内容を提示し、**選択ボタンで明示的な承認を得てから**行う。研究記録を口実に他ファイルを変更しない。
- 承認ボタンを提示した後は、追加の案内文や最終メッセージを送らず、ユーザーの回答を待つ。ボタン提示後のメッセージでボタンが消える可能性への対処であり、表示が維持されることを保証するものではない。
- ボタンが消えるなどして選択できない場合は、提示した変更案に対する「承認します」などの文章による明示的な承認も有効とする。回答がないことや時間の経過を承認と扱わず、承認の対象が曖昧な場合は確認する。ボタン提示が正常にできる場合は従来どおりボタンで確認する。
- `memory/archive/` は過去の記録を保管する場所であり、通常の追記先にはしない。保存済みアーカイブは原則変更しない。

## 2. 実行と確認の担当

- アシスタントは研究コードの作成・静的確認を担当する。ノートブック、生成コード、学習、推論、評価、構文テスト・動作テストの実行はユーザーが行う。
- ユーザーから明示的な実行依頼がある場合のみ、アシスタントが実行する。未実行コードを動作確認済みと表現しない。
- ファイルの読み取り、差分・参照の確認、研究記録の編集、Git操作は継続する。資料作成で生成・描画・表示確認が必要な場合は、その作業範囲を変更承認時に明示する。
- 正式学習用コードの初期値は `RUN_FULL_TRAINING = True` とする。これはアシスタントによる学習実行の許可ではない。

## 3. Git

- ファイル変更後は必要な確認を行い、内容に合うメッセージでローカルコミットまで行う。研究記録の更新も対象。
- **pushはユーザーが行う。アシスタントは行わない。**
- 作業開始時に既存差分を確認し、原則として今回の変更だけをコミットする。「溜まった変更をコミット」など、ユーザーが別途指定した範囲を尊重する。
- モデル重みや実験結果フォルダは、個別の指示がない限り自動で追加しない。

## 4. 資料・コードの管理

- 報告会資料のHTML・Markdownは、リポジトリと指定のOneDriveの両方へ保存する。PPT／PPTXは原則OneDriveのみへ保存する。個別に承認された保存先・例外を優先する。
- AIが作成するスライドは指定先の `AI作成/` に格納し、ファイル名の拡張子直前に `(AI作成)` を付ける。
- 既存資料を残してv2を作るなど、ユーザー指定の版管理を尊重する。未保存のユーザー編集を上書きしない。
- コードは `code/YYYYMM/用途別フォルダ/` に整理し、移動時は参照・ルート探索・一覧の整合を確認する。データや保存済み結果は勝手に移動しない。
- スライドは従来の16:9・明朝体・落ち着いた配色を参考にし、文字・図・表・グラフは可能な範囲で編集可能にする。

## 5. 記録と整合性の維持

- 新しい進捗、実験結果、ユーザーと議論した考察をその都度記録し、報告資料に再利用できるようにする。
- 記録には、日付、対象、実行ID・関連ファイル、条件、結果、考察、限界、未確認の仮説を可能な範囲で添える。コード作成済みと実行済みを区別する。
- **更新時には4ファイルを横断して、矛盾・重複・リンク切れ・古い現在形がないか確認する。** 研究方針の変更時は旧方針を履歴として位置付け、入口の要約と関係する考察も必要に応じて同じ変更で更新する。
- 詳細の管理先は、運用＝本ファイル、研究上の決定＝[研究方針](研究方針.md)、結果・解釈＝[実験結果と考察](実験結果と考察.md)。[memory.md](memory.md)は入口と現在の要約に絞る。
- 過去の結果の条件を新方針に書き換えない。方針変更に伴って過去のコード・モデルを自動変更しない。
- アーカイブの当時の記載と現在の方針が異なる場合、アーカイブは履歴として読む。日付だけでなくユーザーの決定・根拠を確認し、未解決の矛盾を推測で消さない。
