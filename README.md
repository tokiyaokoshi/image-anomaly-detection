# 🛠️ VAEを用いた製造品画像における局所異常検知アルゴリズムの開発

製造現場における目視検査の自動化・DX推進を目指し、深層生成モデルの一種である**変分オートエンコーダ（VAE: Variational Autoencoder）**を活用した画像異常検知アルゴリズムの研究・開発を行うリポジトリです。

---

## 📌 研究の背景と目的

### 1. 製造現場における深刻な人手不足
現代の日本の製造業やインフラ保守点検の現場では、少子高齢化に伴う深刻な人手不足が課題となっています。現在も多くの現場では、熟練の作業員による「目視検査」に依存していますが、これには技術伝承の難しさや、疲労による見逃しのリスクが伴います。

### 2. 外観検査自動化における「AIの課題」
従来の一般的なAI（教師あり学習）で不良品を検知しようとする場合、**「事前に大量の異常データ（キズやへこみの画像）」を収集してAIに学習させる**必要がありました。しかし、実際の優良な工場では不良品はめったに発生しないため、異常データを集めること自体が困難という矛盾（データ準備コストの壁）がありました。

### 3. 本研究が目指す解決策
本研究では、AIに**「正常な製品の姿」だけを記憶させる**ことで、データ準備コストを劇的に削減しつつ、検査業務の自動化を目指します。現場の作業員が単純な目視検査から解放され、より高度な安全管理や設備改善業務に専念できる環境を創り出すことで、社会基盤の持続可能性に貢献します。

## 💡 異常検知の仕組み（初学者向けの解説）

本システムは、VAEの**「学習したことのないものは上手く再現（復元）できない」**という特性を応用しています。

```text
【訓練時（正常のみ）】
正常画像 ──> [ エンコーダ ] ──> 潜在変数 z ──> [ デコーダ ] ──> 綺麗な正常画像（再現成功！）
※AIは「正常とは何か」を完璧に記憶する

【テスト時（未知の異常）】
異常画像 ──> [ エンコーダ ] ──> 潜在変数 z ──> [ デコーダ ] ──> 正常っぽい画像（異常が消える！）

ここで、[ 元の異常画像 ] と [ 復元画像 ] の「差分（再構成誤差）」を計算します。
差が大きい部分 ＝「異常箇所」として特定されます！

1. **正常の学習**: 訓練フェーズでは、傷のない綺麗な製品（例：ボトルの飲み口など）の画像だけをAIに与え、元通りに復元する訓練を繰り返します。
2. **未知の異常への対応**: 学習を終えたAIに、キズのある画像（異常画像）を入力すると、AIは自分が知っている「正常な姿」に無理やり直して復元しようとします。
3. **異常箇所の特定**: 「元の画像」と「AIが復元した画像」を見比べたとき、**キズがあった部分だけ大きなズレ（再構成誤差）**が生じます。この誤差を算出・可視化することで、過去に前例のない未知の欠陥であっても漏れなく特定することができます。
```

## 🚀 本リポジトリのアプローチとこだわり

実運用において、異常の「見逃し」は重大な不良流出や事故に直結するため、実際の異常をAIが漏れなく検知できた割合を示す**「再現率（Recall）」の高さ**が不可欠です。
初期検証では再現率が約50%にとどまっていましたが、これを**実運用レベルである95%以上**に引き上げるため、以下の高度な技術チューニングを実装・検証しています。

### 1. ネットワーク構造の最適化
全結合層（Linear層）の階層数やチャンネル数といったハイパーパラメータの調整、およびCNN（畳み込み）層をベースとしたモデル構築を行い、画像の空間的な構造を壊さずに特徴量を圧縮する内部構造の最適化を進めています。

### 2. KLアニーリング（KL Annealing / β-VAE技術）の導入
VAEの損失関数に含まれる「再構成誤差（MSE）」と「潜在空間の正規性（KLD）」のトレードオフを制御するため、学習の進捗（エポック数）に応じてペナルティ係数 β を動的に変化させる**KLアニーリング**を実装しています。
学習初期は画像の復元性能の獲得に集中させ、後半から潜在空間を整列させることで、復元画像のぼやけ（Posterior Collapse）を防ぎ、検知精度の底上げを図っています。

### 3. 画像前処理による異常の強調
微細な異常を強調する画像前処理を導入しています。対象物の模様やエッジを際立たせる前処理を施すことで、AIが異常を検知しやすくなるよう検証を重ねています。

## 📊 開発環境・データ規模

### 📂 使用データセット
* **分析対象**: 製造品の画像データ（ボトル外観画像等）
* **データ規模**: 計 **292** 枚
  * 訓練用（正常画像のみ）: 209 枚
  * 検証・テスト用（正常・各種異常を含む）: 83 枚

### 🛠 技術スタック
* **開発言語**: Python 3.13
* **主要ライブラリ**: 
  * `torch` (PyTorch) - 深層学習モデルの構築・学習
  * `torchvision` - 画像前処理・データ拡張
  * `PIL` (Pillow) - 画像ファイルの読み込み・基本操作
  * `matplotlib` - 学習曲線・スコア分布・ネットワーク構造の可視化
  * `pathlib` - クロスプラットフォームに対応した堅牢なパス操作
* **実行環境**: Jupyter Notebook

## 📈 今後の展望
目標精度（再現率95%）への到達後は、現在工場などで主流となっている「テンプレートマッチング」や、異常データを大量に必要とする従来の「教師あり学習」といった従来手法との比較検証に移行します。

検知精度や処理時間といった技術的指標だけでなく、**「データ準備コストをどれだけ削減できたか」という現場の運用面**からも、本手法の有用性を客観的に実証していく計画です。
