まず1分で：この論文が伝えたいこと

  1. 正常画像をきれいに復元できても、異常を見つける性能が高いとは限らない。 制約を弱めたVAEは、異常まで残して復元することがある。一方、制約を強くしすぎると正常な構造まで崩れる。
  2. Sparse VAEは、潜在変数の各成分に「学習する強さのノイズ」を加える。 ノイズを受けても必要な正常構造を復元できるように学習させ、不要な成分への依存を弱める。固定のDropoutを追加するだけでは再現にならない。
  3. 改善は、主に模擬病変の場所を見つける評価で示された。 実患者の画像単位AUCでは、手法間に有意な差は報告されなかった。ボトル画像のAUROC向上は、別途検証する必要がある。

1. 何を調べた論文か

［論文：P1、P2 §2.2］ 対象はボトルではなく、脳の3次元FDG PET画像。FDG PETは、脳の各場所での代謝活動を画像化する検査である。正常な脳画像だけで学習し、アルツハイマー病に関連する低代謝などを見つけることを考える。

［解説］ 2次元画像の最小単位が「画素」、3次元画像の最小単位が「ボクセル」。この論文は、単に「この人は正常か」を判断するだけでなく、画像のどこが異常かを示すことを重視する。

［論文：P1、P3 §3〜4］ 重視する条件は、正常画像の再構成の良さ、異常検出の良さ、乱数シードを変えたときの安定性、の3つ。正常を復元した誤差だけでモデルを選ぶことの問題を調べている。

2. VAEを使う異常検知の仕組み

［解説］ VAEは、画像を少数の数値に圧縮し、その数値から画像を作り直すモデル。「圧縮する部分」がエンコーダ、「作り直す部分」がデコーダ、間にある数値の組が潜在変数である。

［論文：P2 §2.1〜2.3］ この研究で期待するのは、異常画像を入れたときに、異常のない擬似正常画像を復元すること。例えば病変を正常な組織へ置き換えられれば、入力と復元画像との差に病変が残る。

［解説］ ここは言葉を取り違えやすい。

異常画像を入力したときの動作入力との差再構成ベース検出への影響
異常まで忠実に復元して残す異常部分の差が小さくなる見逃しの原因になりうる
異常を消し、正常らしい構造へ復元する異常部分の差が残る期待する擬似正常化
正常な構造まで大きく崩す正常な場所にも差が出る誤検出や解釈の難しさにつながる

異常を消して正常へ近づけること自体は、目標の動作である。 問題は、異常をそのまま復元することと、正常部の復元まで悪化することである。

3. なぜ「復元の上手さ」と「検出の上手さ」が両立しにくいか

［論文：P2〜3 §3、図1］ 通常のβ-VAEで、潜在次元を20・64・256、KL項の重みβを0.1・1・10・100に変えた12設定を比較した。

制約の変え方正常画像の復元異常の検出について観察された傾向
潜在次元を大きくする、βを小さくする良くなりやすい異常まで再現し、検出が悪くなることがある
潜在次元を小さくする、βを大きくする悪くなりやすい検出は改善するが、正常部の画像品質を失いやすい

［解説］ βは、潜在変数の分布を基準の分布へ近づける制約の重さ。大きいほど自由な表現を抑える。上の表はこの実験の傾向であり、「どんなデータでも制約を強くすれば良い」という法則ではない。

［論文：P3 §4、図2］ 基準モデルは潜在64次元・β=10。30シードで調べると、正常と異常の潜在分布のずれが大きいモデルほど、擬似正常化が悪くなる傾向があった。著者は、エンコーダとデコーダの滑らかさ、つまり入力や潜在変数の小さな変化に対し出力が極端に変わらない性質が重要だと解釈している。

［解説］ ここで目指すのは、潜在空間で正常と異常を遠く離すことではない。異常入力の潜在表現が正常から外れすぎず、デコーダが正常らしい画像へ戻せることを重視する。潜在距離による分類を主目的とする手法とは、狙いが違う。

4. 比較した2つの改善方法

［論文：P3〜4 §5］

方法何を調整するか調整する単位
周期的βスケジューリング学習中のKL制約の重さβ学習時点ごとに全体の重みを変更
Sparse VAE潜在変数の各成分の相対的なノイズ強度α潜在次元ごとに学習

［論文：P3 §5.1］ βスケジュールは3周期。各周期をβ=0から始め、最大30または50へ増やす。復元を学ぶ期間と、潜在分布を整える期間を繰り返す。

［公式コード：C2］ 設定も3周期・周期内の増加率0.5を指定する。本文は100エポック、公開された周期用設定は99エポックのため、厳密な再現時はこの差を確認する。

［本研究への提案］ 現在のボトル用コードは、50エポックかけてβを0から1へ一度だけ増やす。同じ「アニーリング」でも、この論文の周期方式を再現した状態ではない。 また、βの数値は損失の合計・平均の方法に依存するため、30や50だけをそのまま移すのは避ける。

5. Sparse VAEの核心：各次元に、学習するノイズを与える

［論文：P4 §5.2］ Sparseは「疎」という意味。この論文では、潜在変数の各成分にGaussian Dropoutを使う。復元に重要でない成分ほど強いノイズを受ける方向へ学習され、デコーダがその成分に頼りにくくなる。

［解説］ たとえば、画像を表す64個の数値を、64人から届く情報だと考える。毎回大きく揺れる情報には頼りにくい。復元に必要な情報を残し、あまり役に立たない情報への依存を下げる、という直感で理解できる。ただし、各次元に「キズ担当」などの意味が最初から割り当てられるわけではない。

5.1 固定のDropoutとの違い

比較項目一般的な固定Dropoutこの論文のSparse VAE
ノイズの設定人が確率を固定することが多い次元ごとのαを学習する
値の揺らし方Bernoulli型なら、確率的に0にする平均1のガウス乱数を掛ける形で説明できる
潜在分散Dropoutを別の層として加えることが多い分散自体をα×μ²と結び付ける
損失通常の損失のままの場合が多い疎性を促す専用の正則化項を使う

［解説］ Gaussian Dropoutは、毎回ある割合の成分を厳密に0へ落とす処理と同じではない。「ノイズが強くなり、結果として依存が弱まる」という機能的な疎性を狙う。潜在次元数64を固定で16へ減らす、といった操作でもない。

5.2 αは画像ごとに変わるのか

［論文：P4 式3／公式コード：C3］ αは潜在次元ごとの学習パラメータ。確認した実装では形状は1×潜在次元で、画像間で共有される。一方、平均μ(x)は入力画像からエンコーダが計算する。

α自体は画像ごとの出力ではないが、分散α×μ(x)²は入力画像に依存する。 この2つを区別する。

6. 数式を1つずつ読む

6.1 普通のVAEでは、平均と分散を出力する

［解説］ 対角ガウス分布を使うVAEは、通常、潜在次元ごとに平均μと分散σ²を表現する。

通常のVAE： q(z|x) = N( μ(x), diag(σ(x)²) )

Nはガウス分布、diagは各次元の分散を対角に並べること。ここでは次元間の共分散を0とする分布を使う。

6.2 Sparse VAEでは、分散を平均と結び付ける

［論文：P4 §5.2 式3］ 

Sparse VAE： q(z|x) = N( μ(x), diag(α ⊙ μ(x)²) )

次元iだけを見ると：
平均      = μ_i(x)
分散      = α_i × μ_i(x)²
標準偏差  = √α_i × |μ_i(x)|

［解説］ ⊙は成分ごとの掛け算。αは分散そのものではなく、平均の大きさに対する相対的なノイズ強度である。

仮想例平均μα分散αμ²標準偏差
小さなノイズ20.050.20約0.447
平均の絶対値が大きい60.051.80約1.342
ノイズを強くする21.004.002.000

［解説］ 同じαでも、|μ|が大きいほど絶対的な揺らぎも大きくなる。著者は、正常な潜在表現の周囲にも復元できる範囲が広がり、異常入力のずれを吸収しやすくなると説明している。ただし、任意の異常を正常化できる保証ではない。

6.3 Gaussian Dropoutとのつながり

［解説：式3の数学的な読み替え］ 標準正規乱数εを使うと、同じ分布の値を次のように生成できる。

ε_i ~ N(0, 1)
z_i = μ_i(x) × (1 + √α_i × ε_i)

掛ける乱数の平均は1、分散はα。「平均の値は保ちつつ、相対的なノイズを掛ける」のでGaussian Dropoutと解釈できる。

［公式コード：C3、C4］ 関連するDropout率としてp=α/(1+α)を計算している。逆にα=p/(1−p)。これは、平均1へ補正したBernoulli Dropoutと分散を対応させた関係であり、実際のゼロ化確率をそのまま表すという意味ではない。

α対応するp解釈
約0.0498約4.74%小さめの相対ノイズ
150%平均と同程度の揺らぎ
990%強い相対ノイズ

6.4 初期値log α=−3の意味

［論文：P4 §5.2］ 著者はlog αを−3に初期化した。正常画像の復元誤差が基準β-VAEと同程度になる範囲で、経験的に選んだ値である。

［公式コード：C1、C3］ Sparse設定はβ=1、log_alpha_init=−3。実際の初期化は−3を中心とする標準偏差0.01の小さな乱数を使う。log αを学習すれば、α=exp(log α)は常に正になる。

［本研究への提案］ −3は有力な出発点だが、ボトル画像でも最適とは限らない。正常検証画像の復元品質と、学習後のαの分布を確認する。

7. 損失関数：通常のKL項を、そのまま流用しない

［論文：P4 §5.2］ 論文は、KL項がαを大きくする方向に書き換わると説明するが、Sparse VAE用の近似式は本文に展開していない。

［公式コード：C3、C4］ 著者指定のMultiVaeブランチでは、Sparse設定時に専用のsparse_kl_divergenceへ切り替える。通常の標準正規分布に対するKLとは別の、変分Dropout由来の近似正則化である。

［解説：確認した実装を数式で表現］ 最小化する目的を概念的に書くと、次の形になる。

損失 = 再構成の負の対数尤度 + β × Σ R(log α_i)

R(l) = −k1 × sigmoid(k2 + k3×l)
       + 0.5 × log(1 + exp(−l)) + k1

k1=0.63576, k2=1.87320, k3=1.48695
Sparse設定のβ=1

sigmoidは値を0〜1へなめらかに変換する関数。αが大きくなると、この正則化項は小さくなる。一方、復元に必要な成分へ過度なノイズを与えると再構成損失が増える。「ノイズを増やしたい正則化」と「画像を復元したい学習」の競合によって、成分ごとの依存の強さが調整される。

［公式コード：C4］ μ=0付近の計算を安定させるため、log|μ|の代わりにlog(|μ|+10⁻⁸)を使う。正則化の計算で使うlog αは−8〜8へ制限する。この制限が、サンプリングに使う学習パラメータ全体を同じ範囲に制限する、という意味ではない。

［補足文献：R1］ 近似式の背景は2019年のSparse Multi-Channel VAEに記載され、対数一様の非正規化事前分布に由来する。標準正規事前分布のKLと同一視しない。ここでは、その理論全体の厳密な導出までは行わない。

［本研究への提案］ 分散をαμ²へ変えたうえで、既存の通常VAE用KL式をそのまま使うと、著者と異なる学習になる。サンプリングの変更と専用の正則化をセットで確認する。 復元損失の係数・合計か平均かも揃える必要がある。

8. 学習時にノイズを入れるなら、評価時も毎回揺らすのか

［論文：P2 §2.1］ 論文は再構成を明確に次のように定義している。

評価時の再構成： x̂ = D( μ(x) )

Dはデコーダ。評価では平均μを使って復元する。 学習時に周囲の点から復元する訓練をして、その効果を学習済みデコーダへ残す。

［解説］ 「学習時のノイズで頑健にすること」と「評価時に平均を使って出力を安定させること」は両立する。単純にαの大きい次元を評価時にゼロ化する、と論文は定義していない。

［本研究への提案］ 現在のボトル用評価コードは、model.eval()でも潜在変数を乱数サンプリングする。eval()だけで自作の乱数生成は止まらない。論文に合わせるなら、平均を使う経路を明示する。変更時には、通常VAEも同じ推論方法で比較し直す。

9. どの実験で、どれだけ改善したか

9.1 正常画像と、模擬病変を加えた画像を使う

［論文：P2 §2.2〜2.3］ 学習用は302人の正常被験者から得た545画像。被験者単位で5分割して検証する。正常テスト画像にアルツハイマー病を模した異常を加え、正常な正解画像と異常領域の正解マスクが分かる条件を作る。弱い異常がtest-AD-30、強い異常がtest-AD-50。

［解説］ 「元の正常画像」があるため、異常入力の復元が本当に正常へ近づいたかを測れる。ボトルの実異常画像には通常、同じ個体の無傷画像がないので、この評価をそのまま実施できるとは限らない。

9.4 安定性と、改善しなかった評価

［論文：P4 §5.3］ 30シードでのAPの標準偏差は、基準3.3に対しSparse 2.0。表1の「5分割・シードの標準偏差」とは別の実験結果である。

［論文：P4 §5.3］ 実患者の正常50例・AD50例での画像単位AUCは、全モデルで80.6〜81%程度（0.806〜0.810）。有意な優劣は報告されていない。

［本研究への提案］ 参考にすべき点は、モデル選択を正常復元の良さだけに頼らないこと、乱数による変動を調べること、潜在表現への制約と擬似正常化の関係を検証すること。一方、ボトルのAUROC低下の原因を、この論文だけで確定することはできない。

［本研究への提案］ 潜在KLDスコアとSSIMスコアの統合案も、この論文が直接示した方法ではない。むしろ「異常と正常の潜在分布のずれを減らす」という狙いと、潜在の外れ具合で異常を分類する狙いには違いがある。別の仮説として比較する。

11. 既存コードへ導入するなら、何から進めるか

［本研究への提案：以下は未実施］ 一度にすべてを変更せず、次の順序で比較する。

  1. 評価を固定する。 対象ファイル一覧、正常／異常ラベル、前処理、スコア計算を固定する。閾値選択用と最終テスト用を分ける。平均μによる推論を通常VAEでも確認する。
  2. 既存VAEの基準値を取り直す。 複数シードでAUROC・Recall・F1・正常画像の復元品質を記録する。拡張前後で学習回数・更新回数などがどう変わるかを明示する。
  3. Sparse固有の変更を入れる。 次元ごとの学習パラメータlog α、分散αμ²、専用の正則化項を組み込み、推論時はμを使う。通常のlogvar出力をどう置き換えるかも整理する。
  4. 変える要素を分けて比較する。 通常VAE／Sparse VAEと、拡張なし／ありの組合せを比較する。周期βの実験は別条件として扱う。
  5. 数値と画像を両方見る。 検出指標だけでなく、同じ見逃し画像の入力・再構成・誤差マップ、学習したαの分布を保存する。正常部を壊してスコアを上げただけではないかを確認する。

［解説］ これは本研究向けの移植・比較計画であり、3D PETの実験をそのまま再現する計画ではない。この資料の作成では学習コードを変更せず、新たな学習・評価も行っていない。

用語この資料での意味

［解説／補足文献R2］ 本文P3 §5.1は、σ²→0をposterior collapseと呼ぶ書き方をしている。一般的なVAEでいうposterior collapseは、q(z|x)が事前分布に近づき、zが入力情報を使わなくなる現象を指す。分散が0へ縮むことと、入力情報を失うことを同義として覚えない。 この資料では、ノイズの大きさ・通常KL制約・情報の保持を分けて説明した。

［解説］ 本文の通常KL式2では定数項−1が省略されている。対角ガウスと標準正規の通常KLを厳密に書く場合は、各次元に−1が入る。最適化に無関係な定数の省略と、Sparse専用正則化への変更は別の話である。
