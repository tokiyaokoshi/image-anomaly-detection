# Sparse VAE はじめの一歩

**数式なしで、「何をしているのか」から理解する資料**

作成日：2026年10月16日

読み方は「スパース・ブイエーイー」です。ここでは、今回読んだ論文で使われているSparse VAEを説明します。

最初に、目指していることを一言で書きます。

> **正常な画像を覚えたモデルに、画像の表し方を少し揺らしながら練習させる。それにより、細かな情報に頼りすぎず、正常らしい画像へ戻せるようにしたい。**

この一文は、まだ分からなくて大丈夫です。順番に見ていきましょう。

## 1. まず、何を見つけたいのか

ボトルの口を、真上から撮影した画像があるとします。

- 正常なボトル：縁がつながっている。
- 異常なボトル：縁が欠けていたり、中に汚れがあったりする。

研究の目標は、画像を見て、**異常なボトルを見つけること**です。

しかし、壊れ方や汚れ方には、たくさんの種類があります。すべての異常を、あらかじめ集めるのは大変です。

そこで、「異常を全部覚えさせる」代わりに、**正常な画像だけを使って学習させる**方法を考えます。

## 2. VAEの仕事を「短いメモ」で考える

### 画像を、そのまま保存するのではない

ある人が、ボトルの画像を見て、別の人に絵を描いてもらうとします。

ただし、元の画像は渡せません。代わりに渡せるのは、短いメモだけです。

```text
画像を見る人 → 短いメモ → メモを読んで絵を描く人
```

VAEも、これに似たことをします。

```text
画像を読み取る部分 → 画像の特徴を表す数値 → 画像を作り直す部分
```

この「画像の特徴を表す数値」を、**潜在変数（せんざいへんすう）**と呼びます。この資料では、まず「短いメモ」だと思ってください。

**実際のメモは、日本語の文章ではなく、数字の集まりです。** また、「1つ目の数字は丸さ、2つ目はキズ」と、人が項目を決めているわけでもありません。

### 練習中は、元の画像と見比べる

正常な画像を使い、次の練習を繰り返します。

```text
正常な画像
    ↓
短いメモを作る
    ↓
メモから画像を作り直す
    ↓
元の正常な画像と見比べる
    ↓
似ていなければ、メモの作り方と画像の描き方を調整する
```

作り直した画像を、**再構成画像（さいこうせいがぞう）**と呼びます。「復元した画像」と考えても大丈夫です。

普通のVAEでも、練習中のメモの数値には揺らぎがあります。**「普通のVAEには揺らぎがなく、Sparse VAEだけにある」という違いではありません。**

では、なぜ画像を作り直すことが、異常の発見につながるのでしょうか。

## 3. なぜ異常まで復元すると困るのか

異常な画像を入力したときに、次のようになることを期待します。

```text
入力：キズのあるボトル
          ↓ モデルで画像を作り直す
復元：キズのない、正常らしいボトル
          ↓ 入力と復元を見比べる
違い：キズがあった場所に差が残る
```

**キズが復元画像から消えれば、元の画像と違う場所を調べることで、キズを見つけられます。**

一方、モデルがキズまでそっくり作り直してしまうと、どうでしょうか。

```text
入力：キズのあるボトル
          ↓
復元：同じキズのあるボトル
          ↓
入力との差が小さくなり、見逃すかもしれない
```

つまり、何でも忠実に復元できればよい、というわけではありません。

ただし、復元を下手にすれば解決するわけでもありません。正常なボトルの縁まで崩れてしまうと、正常な場所にも大きな差が出て、異常と間違えてしまいます。

欲しいのは、**正常な部分はきれいに残し、異常な部分は正常らしく戻すモデル**です。

ここに書いた「キズを消す動作」は目標です。正常画像だけで練習したからといって、必ずそうなるわけではありません。

## 4. Sparse VAEは「短いメモ」に何をするのか

### メモの数値を、練習中に少し揺らす

短いメモに、4つの数字の欄があるとします。

```text
元のメモ      ［10、20、30、40］
揺らしたメモ  ［11、18、34、39］
```

これは、仕組みを説明するための架空の例です。数字に「丸さ」「色」などの決まった意味はありません。

Sparse VAEは、このように**メモの数値を揺らした状態でも、元の正常な画像を復元できるように練習**します。

元の画像を汚す話ではなく、画像を読み取った後の「内部のメモ」を揺らす話です。

### 欄ごとに、揺らぎの強さを調整する

Sparse VAEでは、それぞれの欄に「どれくらい揺らすか」という調整つまみが付いている、と考えてください。

```text
メモの欄       A        B        C        D
               │        │        │        │
揺らぎの強さ   小       大       小       大
```

毎回大きく揺れるBやDの情報には、画像を作る側も頼りにくくなります。

ここで大切なのは、**どの欄のつまみを、どれくらい強くするかも、学習する**ことです。人が最初から「BとDはいらない」と指定するわけではありません。

このつまみは、画像1枚ごとに別々に用意するのではなく、メモの欄ごとに用意して、画像の間で共通に使います。

また、同じつまみでも、その欄の数値の大きさに応じて、実際に加わる揺れの大きさは変わります。今は、**「全部の欄へ同じ量を足しているわけではない」**と押さえれば十分です。

## 5. なぜ揺らすことが、役に立つ可能性があるのか

### 少し違うメモでも、同じ正常画像へ戻す練習になる

いつも全く同じメモだけで練習していると、メモの数字が少し変わったとき、全く違う画像を描いてしまうかもしれません。

そこで、正常画像から作ったメモを少しずつ揺らしながら、それでも元の正常画像へ戻す練習をします。

```text
少し揺れたメモ① ─┐
少し揺れたメモ② ─┼→ どれからも、元の正常画像に近い画像を作る練習
少し揺れたメモ③ ─┘
```

これにより、メモが多少変わっても、画像の作り方が急に大きく変わりにくくなることを狙います。

もし異常画像を入れたときのメモも、その「正常へ戻せる範囲」に入れば、異常を含む入力から正常らしい画像を作れるかもしれません。

**「かもしれない」が重要です。あらゆる異常のメモが、その範囲に入る保証はありません。**

### なぜ、必要な情報まで失わないのか

Sparse VAEの練習には、2つの方向が同時にあります。

| 練習のルール | その働き |
| --- | --- |
| 元の正常画像を、きちんと復元する | 復元に必要な情報を失うと、成績が悪くなる |
| 各欄の揺らぎを強くする方向にも働きかける | 役に立たない欄へ、むやみに頼り続けにくくする |

例えば、ある欄を強く揺らしても復元がほとんど困らないなら、その欄への依存を減らせるかもしれません。反対に、揺らすと正常な形が崩れるなら、復元を良くする方向の学習が働きます。

この両方の兼ね合いで、メモの使い方が変わっていきます。

**Sparseは「疎（そ）」という意味です。ここでは、全部の欄へ同じように頼るのではなく、一部の欄への依存を弱めることを目指します。**

ただし、何個の欄を使うかが自動で必ず決まる、と考える必要はありません。実際にどのような使い方になったかは、学習後に確認します。

## 6. 普通のVAEとの違いと、よくある勘違い

### 違いを、3つに絞る

| 見るところ | この論文で比較する普通のVAE | この論文のSparse VAE |
| --- | --- | --- |
| メモの揺らぎ | 入力から、中心の値と揺らぎの大きさを表す | 中心の値の大きさと、欄ごとに学習するつまみを組み合わせる |
| メモの使い方を整えるルール | 普通のVAE用のルールを使う | 疎性を促す、専用のルールを使う |
| 目指す効果 | 正常な画像を復元する | 正常の復元を保ちつつ、不要な欄への依存や小さな変化への弱さを減らしたい |

**揺らぎの作り方と、学習のルールを組み合わせて変える**のがポイントです。

### ここだけは取り違えない

- **学習中に「ここがキズ」と教える方法ではありません。** 正常な画像を復元する練習から、メモの使い方を学びます。
- **キズの情報だけを見分けて消す装置ではありません。** どの情報が異常かを直接知っているわけではありません。
- **メモを決まった割合で0にするだけの方法ではありません。** この論文では、数値へ連続的な揺らぎを与えます。
- **欄の数を最初から減らす方法とも違います。** 欄への頼り方を、学習で変えることを考えます。

### 練習が終わった後も、毎回揺らすのか

この論文では、画像を調べるときは、メモの「中心となる値」を使って復元します。

**練習中は揺らぎに慣れさせ、調べるときは中心の値を使う**、という分け方です。

### 自分のボトル画像でも、必ず良くなるのか

まだ分かりません。論文は脳の画像を使った実験で、異常の場所を見つける評価などに改善がありました。一方で、実患者の画像を1枚ずつ正常・異常に分ける評価では、はっきりした改善は報告されていません。

ボトルでも同じ効果があるかは、実際に比較して調べる必要があります。

## 7. 自分の言葉で説明してみる

答えを読む前に、ひと呼吸置いて考えてみてください。

### 問い1：なぜ、キズまでそっくり復元すると困るのでしょうか

**答え：** 入力と復元画像の違いが小さくなり、キズを見逃すかもしれないからです。

### 問い2：Sparse VAEは、画像そのものと、内部のメモのどちらを揺らすのでしょうか

**答え：** 内部のメモです。揺らしたメモからも、元の正常画像を復元できるように練習します。

### 問い3：なぜ、全部のメモをめちゃくちゃにするわけではないのでしょうか

**答え：** 正常画像をきちんと復元する、というルールもあるからです。必要な情報まで使えなくすると、復元の成績が悪くなります。

### 問い4：Sparse VAEは、キズを必ず消せる方法でしょうか

**答え：** いいえ。正常らしい画像へ戻せるようになることを狙う方法で、効果はデータや学習の仕方によって変わります。

最後に、友達へ説明するつもりで、次の文章を読んでみてください。

> VAEは、画像を短い数字のメモにして、そのメモから画像を作り直す仕組みです。Sparse VAEは、メモの欄ごとに揺らぎの強さを学び、揺れたメモからも正常画像を復元する練習をします。不要な情報へ頼りすぎず、少し違うメモでも正常らしい画像へ戻せるようになることを狙います。ただし、キズを必ず消せるわけではありません。

## たとえ話と、実際の仕組みの対応

ここは、専門用語へ進みたくなったときに読んでください。

| この資料の言い方 | 実際の呼び方 |
| --- | --- |
| 短い数字のメモ | 潜在変数 |
| メモを作る部分 | エンコーダ |
| メモから画像を作る部分 | デコーダ |
| メモの中心の値 | 平均μ（ミュー） |

| 学習のルールを数値にしたもの | 損失関数 |

「メモ」や「つまみ」は説明用のたとえです。内部に文章が書かれたり、物理的なつまみがあったりするわけではありません。
