## 開き方と参照パス

- 上のリンク、またはIDEの月別フォルダから開きます。リポジトリ内での新しいパスは `code/YYYYMM/ファイル名.ipynb` です。
- 10月のルート探索処理と、保存済みノートブックを読む比較処理は、新しい配置に合わせて更新しています。
- `data/`、`saved_models/`、図の出力先は従来の場所を使います。保存済みの学習結果を月別フォルダへ移したわけではありません。
- 6〜7月の過去のノートブックには、当時のLinux／Windows環境の絶対パスが残っています。今回それらの環境設定や学習処理は変更していません。再実行する場合は、各設定を確認してください。
- 比較学習ノートブックの「すべて実行」は、設定によって学習を開始します。保存済みの学習曲線を見るだけなら、末尾の「保存済みログから学習曲線を表示する」のセルを実行できます。
