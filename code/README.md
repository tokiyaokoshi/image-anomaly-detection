- 上のリンク、または `code/YYYYMM/用途別フォルダ/` から開きます。今後のノートブックも対応する月・用途のフォルダへ保存します。
- `data/`、`saved_models/`、図の出力先は従来の場所です。今回の整理でデータ・モデル・実験結果は移動していません。
- 移動に伴う相対リンク、ルート探索の目印、保存済みノートブックの読込先を更新しました。学習条件・保存済み出力・実行番号は維持しています。
- 表中の「未実行」「コード作成のみ」は作成時の記録です。その後のユーザー実行・結果は各ノートブックの保存済み出力とmemory.mdを参照してください。
- 6〜7月のノートブックには当時のLinux／Windows環境の絶対パスが残っています。今回それらの環境設定や学習処理は変更していません。再実行する際は設定を確認してください。
- 「すべて実行」は学習を開始する場合があります。保存済みログを読むセルと学習セルを区別してください。今回アシスタントはノートブックを実行していません。
